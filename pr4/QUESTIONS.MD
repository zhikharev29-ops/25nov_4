# Контрольные вопросы

## 1. Какой момент времени выбирает PHP для вызова автозагрузчика и что произойдёт, если файл класса так и не найден?
PHP вызывает автозагрузчики в момент первого обращения к классу, который ещё не загружен: например, при `new User()` или при вызове статического метода. Если ни один из зарегистрированных автозагрузчиков не подключил нужный файл, PHP выдаёт ошибку `Class "User" not found`.

## 2. В чём преимущество spl_autoload_register() перед удалённой функцией __autoload()?
`__autoload()` в проекте мог быть только один, и он удалён из PHP начиная с версии 8.0. Через `spl_autoload_register()` можно зарегистрировать несколько автозагрузчиков, и PHP вызывает их по очереди. Благодаря этому свой загрузчик и загрузчик подключённой библиотеки (например, от Composer) не мешают друг другу. Кроме того, загрузчиком может быть любая функция: анонимная, метод класса и т. д.

## 3. Чем абстрактный класс отличается от интерфейса? Когда что выбрать?
Интерфейс содержит только сигнатуры методов, без реализации и без обычных свойств, и класс может реализовывать сколько угодно интерфейсов. Абстрактный класс может хранить и реализацию (обычные методы), и состояние (свойства, константы), но наследоваться можно только от одного класса.
Интерфейс выбирают, когда нужен общий контракт для разных, не связанных между собой классов (например, способы оплаты). Абстрактный класс выбирают, когда есть семейство похожих сущностей с общим кодом (например, фигуры или сотрудники): общее лежит в родителе, а отличающееся реализуют наследники.

## 4. Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?
Объект абстрактного класса создать нельзя: `new` даст ошибку. Создавать можно только объекты наследников. Абстрактное свойство объявить тоже нельзя, абстрактными в PHP бывают только методы (и сам класс). Если нужно, чтобы у наследников обязательно было какое-то свойство, используют абстрактный геттер или конструктор абстрактного класса.

## 5. Чем static-свойство отличается от обычного? Как обратиться к нему внутри и вне класса?
Обычное свойство хранится у каждого объекта отдельно. Статическое принадлежит классу и одно на все объекты: если изменить его, изменение видно везде. Внутри класса к нему обращаются через `self::$count`, снаружи через `ИмяКласса::$count`, если свойство `public`. Для `private` статического свойства нужен публичный статический метод, например `getCount()`.

## 6. Что делает модификатор readonly и какие ограничения он накладывает?
`readonly` разрешает записать значение свойства только один раз, обычно в конструкторе, а потом свойство можно только читать. Попытка изменить его снова даёт `Error: Cannot modify readonly property`. Ограничения: у такого свойства должен быть указан тип, нельзя задать значение по умолчанию, а записать его можно только из самого класса.
